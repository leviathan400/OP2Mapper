# OP2Mapper

![Screenshot](https://images.outpostuniverse.org/OP2Mapper3.png)

OP2Mapper3 - A modern Outpost 2 map editor and map maker. Edit the tiles and the cell types of a .map file.

## Related Projects

- [OP2MissionEditor](https://github.com/leviathan400/OP2Mapper2) - A newer map editor from 2019
- [OP2Mapper2](https://github.com/leviathan400/OP2Mapper2) - The original OPU map editor from 2005
- [OP2UtilityDotNet](https://github.com/leviathan400/OP2UtilityDotNet) - .NET library for working with OP2 files
